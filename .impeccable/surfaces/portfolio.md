# AmberLink public portfolio

Mode: Experience.

Approved visual direction: delegated choice from the user's request to be surprised and instruction to implement the plan. The approved comp is .impeccable/mocks/decision/lobby-bento.png.

World: keep AmberLink's cream, spruce, and amber identity; extend it into a highly detailed, photoreal forest at blue-hour with natural amber-resin details and restrained glass UI.

Home composition: Vinícius Lopes and the existing Portuguese positioning sit beside a clear game-style bento route board for Projetos, Sobre, Artigos, Contato, and Jogar Snake. Real project content remains data-driven from published API cases. The home should read as a portfolio lobby, not a conversion landing page.

Visitor path: choose a destination from the lobby, inspect cases or written work in coordinated public pages, or enter Snake. Internal pages retain compact public navigation. Admin UI stays outside this visual scope.

Signature interaction: scroll reveals and subtle parallax bring forest layers and section panels into view; reduced-motion users get stable static scenes. Snake remains a small 2D playable feature with keyboard and swipe controls.

Risk: the forest can obscure content or overtake the work; keep high-contrast surfaces, real case imagery, and page information visually dominant.
